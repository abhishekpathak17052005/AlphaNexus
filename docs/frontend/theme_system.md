# ALPHANEXUS – Theme System

## 1. Supported Themes

- **Dark Theme (Default):** Bloomberg/terminal-inspired deep blue palette (`#0b0f19`) engineered to minimize eye strain during long equity research sessions.
- **Light Theme:** Crisp executive reporting palette (`#f8fafc`) with soft glass shadows.

---

## 2. CSS Variables

```css
:root {
  --bg-primary: #0b0f19;
  --bg-card: rgba(17, 24, 39, 0.70);
  --accent-blue: #3b82f6;
  --accent-emerald: #10b981;
  --accent-rose: #f43f5e;
  --text-primary: #f9fafb;
  --text-muted: #9ca3af;
}
```
