# ALPHANEXUS – Liquid Glass Design System

## 1. Principles

- **Translucency & Depth:** Surfaces use `backdrop-filter: blur(16px)` with layered alpha transparency to create physical depth without visual clutter.
- **Specularity & Radiance:** Subtle 1px borders with top-edge specular highlights (`rgba(255, 255, 255, 0.12)`).
- **Financial Contrast:** Strict WCAG AAA compliance for numerical figures, delta badges, and citation sources.
- **Data-First:** UI chrome recedes into the background, ensuring charts, tables, and financial evidence stand out.
