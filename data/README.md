# ALPHANEXUS Data Storage Directory

This directory stores ingested filings, processed chunk representations, market datasets, and cache files:

- `uploads/`: Raw uploaded company documents (PDFs, DOCX, XLSX).
- `processed/`: Extracted tabular markdown, tables, and cleaned text artifacts.
- `datasets/`: Pre-curated NSE/BSE corporate ticker metadata and financials.
- `cache/`: Local embedding cache and temporary query cache.
- `sample_documents/`: Test annual reports and quarterly filings for validation.
